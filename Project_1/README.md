**Project Summary**
In this project, we expand upon the k_means study by Nakamura et al. by examining damages caused by hurricanes. We accomplish this by visualizing power outages across affected states along with the hurricane's location and respective intensity (wind speed) at each timestep. We updated the Nakamura et al. model to cluster on landfall location centroids and compare these clusters to the outage data.
